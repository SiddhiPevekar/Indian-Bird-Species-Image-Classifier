# Indian Bird Species Classification

A deep learning system for classifying 25 Indian bird species using transfer learning and ensemble learning.

## Models

- ResNet50
- EfficientNetV2-B0
- MobileNetV2
- Vision Transformer ViT-B/32

## Ensemble Methods

- Linear Mean Ensemble
- Geometric Mean Ensemble

## Tech Stack

- PyTorch
- TorchVision
- timm
- scikit-learn
- Streamlit

## Features

- 25-class Indian bird classification
- Transfer learning
- Image augmentation
- Multi-model evaluation
- Top-3 predictions
- Precision, Recall, F1 and MCC
- Confusion matrices
- Linear and geometric ensemble learning
- Interactive web application
